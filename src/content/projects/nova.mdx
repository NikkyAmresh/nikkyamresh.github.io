## What it does

Open the page, talk, and Nova answers out loud. It can set, list and cancel reminders by voice
("every weekday at 9 remind me to stand up"), stored in [Kitten](/projects/kitten) through its MCP
endpoint and delivered as phone notifications.

## Architecture

| Part | Service |
| --- | --- |
| Speech to text | Whisper large-v3-turbo (Groq) |
| Brain | open-weight LLM on Groq |
| Voice | Piper, running on the CPU |
| Pipeline | Pipecat over a FastAPI WebSocket |

The browser streams 16 kHz PCM over a WebSocket and plays 24 kHz PCM back, so it runs behind a
Cloudflare tunnel with no open ports.

## Interesting problems I solved

**Barge-in.** When you start talking, the bot stops mid-sentence and the page drops any queued
audio, so conversations feel natural instead of turn-based.

**Running for free.** Every part runs on free tiers or the CPU, with an access code so a public URL
cannot burn the API quota.
